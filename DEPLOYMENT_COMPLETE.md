## 🔧 Technical Highlights

### Architecture Decisions
1. **Monorepo → Single Frontend Deployment**
   - Copied backend to `frontend/src/backend/`
   - Simplified deployment to Vercel
   - Removed workspace dependency complexity

2. **File Storage for MVP**
   - Used `/tmp/inkloom.json` on Vercel
   - Simple and fast for demo
   - Easy upgrade path to database

3. **Deterministic Validation**
   - No AI in validation = predictable results
   - Case-insensitive RegExp matching
   - Clear evidence for every finding

4. **3D Graphics with Graceful Degradation**
   - WebGL with Three.js for visual impact
   - Fallback components for unsupported browsers
   - Accessibility: reduced-motion support
